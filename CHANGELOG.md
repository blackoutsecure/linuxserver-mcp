## [0.1.1] - 2026-02-20

### Added
- LinuxServer.io MCP server scaffold with LSIO-oriented tooling.
- Tool: `lsio.validate_spec` for convention validation.
- Tool: `lsio.generate_scaffold` for Dockerfile/README/Compose starter content.
- Tool: `lsio.get_guidance_links` for official LSIO reference mapping.
- Tool: `lsio.get_best_practices` for implementation and review checklists.
- Node.js built-in test coverage for validation and scaffold behavior.
- GitHub Packages release workflow and community sponsorship metadata.

### Changed
- Expanded repository standards and governance guidance in Copilot instructions.
- Added LSIO-aligned file header standards for source and workflow files.
